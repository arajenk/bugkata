# bugkata

a Claude Code plugin to practice reviewing and debugging realistic code

## install

```
/plugin marketplace add arajenk/bugkata
/plugin install bugkata@bugkata
```

## status

very early. right now there's only `/bugkata:start` (a test probe, not real challenges yet) and `/bugkata:help`. the full design lives in [CLAUDE.md](CLAUDE.md).
